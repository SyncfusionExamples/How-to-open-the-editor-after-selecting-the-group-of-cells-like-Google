# EJ2 React

> This sample demonstrate the way to open the editor window immediately after the selecting the group of cells like Google.

# Project prerequisites
Make sure that you have the compatible versions of Visual Studio Code installed on your machine before starting to work on this project. It is also recommended to have a basic understanding of HTML, JavaScript, and the Syncfusion EJ2 components so you can easily explore and modify the sample if needed.

## How to run this application

To run this application, you first need to clone the [How-to-open-the-editor-after-selecting-the-group-of-cells-like-Google](https://github.com/SyncfusionExamples/How-to-open-the-editor-after-selecting-the-group-of-cells-like-Google) repository and then open it in Visual Studio Code. 

 After that, install all required dependencies by running the `npm install` command in the project directory. Once the installation is complete, build and run your project using the `npm start` command. This will launch the application so you can view the output in your browser and test the opening the editor window after selecting group of cells funtionality like google.
